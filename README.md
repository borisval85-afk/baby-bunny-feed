# baby-bunny-feed

Публичный товарный фид для `baby-bunny.ru` — производный, с полным размерным
рядом (не авто-фид KIT). Генерируется скриптом
[`scripts/feed_generator.py`](https://github.com/borisval85-afk/baby-bunny-website/blob/main/scripts/feed_generator.py)
из репозитория `baby-bunny-website`, обновляется раз в сутки.

Почему отдельный фид — разбор в `baby-bunny-website/data/feed-audit.md`
(чат 03, 23.09.2026): авто-фид KIT отдаёт один размер на товар вместо
всего размерного ряда.

**URL фида:** https://borisval85-afk.github.io/baby-bunny-feed/products.xml

Ничего, кроме сгенерированного YML, здесь не хранится — цены и остатки
и так публичны на сайте и в старом авто-фиде.
